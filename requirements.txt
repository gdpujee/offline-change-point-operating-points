#   * results/raw/tcpd_main.json reproduces exactly under A and differs from the
#     committed file at 646 leaf values (1 ULP) under B;
#   * results/raw/landscape.json and results/raw/phantom_impact.json reproduce

# (see Appendix B, "Determinism, precisely"). Two consequences worth stating:
# a rerun in a single environment will show last-bit differences in a subset of
# the raw files, and the figure PNGs are not byte-stable across matplotlib
# versions (3.10.9 vs 3.11.2 changes the rendered bytes, not the plotted values).
